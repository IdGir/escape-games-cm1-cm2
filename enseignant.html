🎯 Ma séance

🛠️ À faire une seule fois : adresse fixe, QR code, favori, PC qui démarre tout seul

1. Réserver l'adresse du PC sur la box de l'école (pour que l'adresse des élèves ne change plus). Outil : le navigateur du PC de l'enseignant.

  1. Lancez le serveur (double-clic sur lancer.bat) et notez l'adresse affichée (ex. http://192.168.1.23:8000/).
  2. Notez l'adresse physique (MAC) du PC : touche Windows, tapez cmd, Entrée, puis tapez ipconfig /all et Entrée ; relevez la ligne « Adresse physique » de la carte Wi-Fi ou Ethernet utilisée.
  3. Ouvrez l'interface de la box dans le navigateur (souvent http://192.168.1.1, ou l'adresse écrite sous la box) et connectez-vous (identifiant de l'école, ou demandez-le au référent numérique).
  4. Cherchez le menu « DHCP », « Réseau local » ou « Baux statiques » puis « Ajouter une réservation » (ou « Bail statique ») : choisissez le PC (ou collez son adresse MAC) et gardez l'adresse IP actuelle.
  5. Enregistrez, puis redémarrez le PC : l'adresse affichée par le serveur doit rester la même.
  6. Si la box est gérée par la mairie ou l'académie : envoyez au référent l'adresse MAC et demandez « une réservation DHCP pour ce PC ».

2. QR code et favori sur les Chromebooks. Ouvrez tableau.html au vidéoprojecteur (bouton « Plein écran »). Sur chaque Chromebook, la première fois : ouvrez Chrome, scannez le QR code (appareil photo) ou tapez l'adresse affichée, Entrée, puis cliquez sur l'étoile ☆ à droite de la barre d'adresse → « Terminé ». Ensuite les élèves cliquent sur ce favori : ils ne voient qu'un bouton « ▶ Jouer » quand une séance est lancée.

3. PC de l'école qui se met à jour et lance le serveur tout seul. Une fois : Explorateur de fichiers → dossier du projet → double-clic sur installer-ecole.bat → suivez la fenêtre. À chaque ouverture de session Windows, le PC récupère la dernière version (git, ou l'archive de GitHub si git est absent) puis lance le serveur. Pour l'enlever : double-clic sur desinstaller-ecole.bat. Détails dans le README (« PC de l'école »).

Sans serveur (site en ligne) : « Lancer » fabrique un lien …/?jeu=… à donner aux élèves (ou à projeter avec son QR code) ; les résultats restent dans les Chromebooks (à relever dans resultats.html).

    ❓ Comment faire ?
    
  
    
    
    Lancer le serveur de la classe
    Outil : l'Explorateur de fichiers de Windows.
      
      
    1. Ouvrez le dossier des jeux (PC principal : E:\IDRISS\PROJET ESCAPE GAMES).
      2. 
      
    2. Double-clic sur lancer.bat : une fenêtre noire s'ouvre, l'ancien serveur est fermé tout seul.
      3. 
      
    3. La fenêtre affiche la version et l'adresse des élèves ; ce tableau de bord s'ouvre dans le navigateur.
      4. 
      
    4. Laissez la fenêtre noire ouverte pendant la séance (la fermer arrête le serveur).
    
    
    Lancer une séance
    Outil : ce tableau de bord.
      
      
    1. Dans « Ma séance », cliquez sur le jeu prévu (ou choisissez-en un autre) et le niveau.
      2. 
      
    2. Cliquez sur 1 · Préparer : le pack d'impression s'ouvre (fiche de mission, évaluation, leçons).
      3. 
      
    3. Cliquez sur 2 · Lancer : la page du QR code s'ouvre ; projetez-la.
      4. 
      
    4. Les élèves scannent le QR code (ou ouvrent leur favori) : ils ne voient qu'un bouton « ▶ Jouer ».
    
    
    Terminer et imprimer le bilan
    Outil : ce tableau de bord.
      
      
    1. Cliquez sur 3 · Terminer.
    2. Le bilan de séance s'ouvre : imprimez-le ou enregistrez-le en PDF.
      3. 
      
    3. Le passeport de compétences est mis à jour tout seul ; ouvrez-le depuis « Après la séance ».
    
    
    Mettre à jour le PC de l'école
    Outil : l'Explorateur de fichiers du PC de l'école.
      
      
    1. Le plus simple : fermez la session Windows puis rouvrez-la (mise à jour automatique si installer-ecole.bat a été lancé une fois).
      2. 
      
    2. Sinon : double-clic sur demarrer-ecole.bat dans le dossier des jeux.
      3. 
      
    3. Ou, sur ce PC, dans « Mes installations » : bouton Mettre à jour cette installation.
    
    
    Mettre à jour la copie Nextcloud
    Outil : l'Explorateur de fichiers du PC principal.
      
      
    1. Double-clic sur mettre-a-jour-nextcloud.bat (ou bouton « Mettre à jour cette installation » sur le PC principal).
      2. 
      
    2. Lisez l'essai, puis tapez O et Entrée.
      3. 
      
    3. Si le dossier est introuvable : copiez le chemin de la copie (barre d'adresse de l'Explorateur), collez-le sur la 1re ligne de outils-ecole\dossier-nextcloud.txt (Bloc-notes), enregistrez, recommencez.
    
    
    Publier sur le site en ligne
    Outil : l'Invite de commandes du PC principal. Jeux sensibles : relecture d'abord.
      
      
    1. Touches Windows + R, tapez cmd, Entrée.
      2. 
      
    2. Tapez cd /d "E:\IDRISS\PROJET ESCAPE GAMES", Entrée.
      3. 
      
    3. Tapez git push origin escape-games, Entrée.
      4. 
      
    4. Une minute plus tard, la ligne « Site en ligne » de « Mes installations » affiche le nouveau numéro.
    
    
    Le dossier des résultats est en rouge
    Outil : le Bloc-notes.
      
      
    1. Ouvrez dossier-donnees.txt dans le dossier des jeux (s'il existe).
      2. 
      
    2. Vérifiez que le chemin écrit sur la 1re ligne existe (clé USB branchée, dossier présent), ou effacez la ligne pour utiliser le dossier des jeux.
      3. 
      
    3. Enregistrez, puis relancez lancer.bat.
    
    
    La sauvegarde est en orange
      
      
    1. Les résultats sont copiés tout seuls chaque jour dans sauvegardes-resultats : rien à faire.
      2. 
      
    2. Sauvegarde complète du projet : laissez le PC principal branché, en veille, le dimanche soir ; vérifiez que le disque de outils-medias\nuit\dossier-sauvegarde.txt est branché.
    
    
    Un problème que je ne comprends pas
    Outil : l'Explorateur de fichiers.
      
      
    1. Double-clic sur diagnostic.bat dans le dossier des jeux.
      2. 
      
    2. Le Bloc-notes s'ouvre sur diagnostic.txt (aucun prénom d'élève dedans).
      3. 
      
    3. Envoyez ce fichier dans la conversation avec Claude.
