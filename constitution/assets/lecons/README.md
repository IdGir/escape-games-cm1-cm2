# Fiches officielles — leçons du jeu

Les leçons de l'escape game (bouton 📚 pendant la partie) **sont** les documents
téléchargeables du site [Découvrons notre Constitution](https://www.decouvronsnotreconstitution.fr/),
édité par le Conseil constitutionnel avec le ministère de l'Éducation nationale.

Ce dossier contient les **16 fiches** attendues (environ 30 Mo au total).

## Installer les fiches

**Le plus simple :** double-cliquez sur `telecharger-fiches.bat` (Windows).
Le script télécharge les 16 fichiers ici, sous les bons noms, et ignore ceux déjà présents.

**À la main :** ouvrez chaque lien du tableau ci-dessous, enregistrez le PDF dans ce dossier,
et renommez-le exactement comme indiqué dans la colonne « fichier attendu ».

> Si un fichier manque, le jeu **reste jouable** : la leçon affiche alors un bouton
> vers la fiche en ligne sur le site officiel.

## Conditions de réutilisation

> Contenus librement diffusables et reproductibles pour un usage non commercial, sous réserve de citer la source, de conserver le titre, la date d'extraction et le nom de l'illustrateur, et de ne pas altérer les contenus (mentions légales du site).

La mention de source suivante est affichée dans le jeu, sous chaque document :

```
Source : Conseil constitutionnel / Découvrons notre Constitution - www.decouvronsnotreconstitution.fr
Illustrations cycle 3 : Fabrice Mosca. Infographies : Amélie Blanquet (Play Bac Presse). Textes et jeux : Bayard Jeunesse.
```

Date d'extraction des fiches : **19/09/2026**.

## Changer ou ajouter une fiche

Tout se règle dans `../data/lecons.json` : chaque entrée indique le titre affiché,
le nom du fichier, l'URL officielle, la salle du jeu et les notions abordées.
Le script `telecharger-fiches.bat` est généré à partir de ce fichier : si vous ajoutez
une fiche, ajoutez aussi sa ligne dans le script (ou demandez sa régénération).
