## À contrôler

1. **Libellé exact du programme** : le texte officiel (Légifrance / BO) n'a pas pu être ouvert directement. Vérifier sur
   Eduscol l'intitulé exact du thème de CM1 et de sa question directrice, cités dans le guide (section 1).
2. **Le cens** : présenté comme une somme d'argent fixe versée **chaque année** pour la tenure (définition des manuels).
   Une source jeunesse consultée parle d'un versement mensuel, ce qui paraît erroné. Garder « chaque année ».
3. **Corvée** : le jeu reste qualitatif (« quelques jours »). Une source évoque une à six journées par an ; le nombre varie
   beaucoup selon les lieux et les époques : ne pas donner de chiffre en classe.
4. **Affranchissement des serfs** « à partir des XIIe et XIIIe siècles » (leçon 5, CM2) : tendance générale, variable selon
   les régions ; formulation volontairement large.
5. **Aliénor d'Aquitaine** héritière du duché d'Aquitaine au XIIe siècle (énigme 3-3 CM2) : fait classique, source citée
   (Encyclopædia Universalis) non consultée en ligne pendant la production.
6. **Mâchicoulis** : la fiche de l'académie les date des XIIe-XIIIe siècles ; les mâchicoulis de pierre se généralisent
   surtout plus tard (les hourds de bois les précèdent). Le jeu ne date pas précisément les mâchicoulis ; le guide rappelle
   que tous les châteaux n'en ont pas.
7. **Pages et écuyers** : le parcours page → écuyer → chevalier est présenté comme le cursus type d'un jeune noble.
8. **Sites cités sans consultation directe** : guedelon.fr, citedelarchitecture.fr, lumni.fr, histoire-image.org (liens
   génériques vers les ressources de référence demandées).
