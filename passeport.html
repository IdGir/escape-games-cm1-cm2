🎓 Passeport de compétences

Les compétences du programme travaillées dans les escape games, cumulées jeu après jeu pour chaque élève, sur toute l'année.

1. La classe

Un prénom (et l'initiale du nom) par ligne. Les données restent dans ce navigateur, sur cet appareil : pensez à exporter (💾) pour les garder ou les transférer.

⏱️ Temps majoré (PAP / PPS) — réglage discret, sur cet appareil seulement

Pour un élève qui bénéficie d'un aménagement de temps : le jeu juge le bonus de rapidité et l'alerte de durée sur son allure (temps réel ÷ coefficient). Rien ne s'affiche chez les élèves : ni message, ni icône, ni dans le bilan. Pour une équipe, le coefficient du membre qui en a le plus besoin est retenu. Ces données ne sont jamais dans les exports « Ma progression » ni dans les comptes-rendus. Fermez ce volet avant de projeter la page.

Composition des équipes (facultatif, une équipe par ligne : Nom de l'équipe : élève, élève). Un élève qui joue seul est reconnu par son prénom.

🧾 Export pour le LSU (bilans périodiques)

👪 Fiche synthèse pour les familles

Une demi-page en langage de tous les jours : le jeu, 2 ou 3 points travaillés, une phrase sur le déroulé. Elle est fabriquée à partir du passeport (ou de la dernière partie d'une équipe) : rien à rédiger. Vous pouvez la relire et ajouter un mot avant de l'imprimer ou de la copier dans l'ENT ou le cahier de liaison numérique.

2. Changer d'appareil : maison ↔ classe

Pour qu'un élève continue chez lui ce qu'il a commencé en classe (ou l'inverse), sans serveur ni compte : il emporte sa progression (compétences du passeport et parties jouées, pour ses trophées) dans un fichier ou un code court, puis l'importe sur l'autre appareil. L'import fusionne avec ce qui est déjà là : la note la plus récente de chaque compétence est gardée, rien n'est écrasé. Sur l'écran d'accueil de chaque jeu, le bouton « 🎓 Ma progression » fait la même chose.
