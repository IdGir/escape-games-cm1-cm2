✅ À relire

Chaque point à vérifier, avec le lien vers le jeu, les sources pour trancher, et un bouton pour le valider.

Comment faire, point par point (1 minute) :
  1. Cliquez sur un lien « Jouer » ou « Leçons A4 » pour voir le passage concerné (l'énigme ou la salle est indiquée en gris).
  2. Cliquez sur une source (bleu) : comparez ce qu'elle dit avec le texte du point.
  3. Si c'est juste : ✓ Valider. Si c'est faux ou douteux : ✗ À corriger (notez pourquoi), puis « Copier les points à corriger » et collez-les à Claude.
