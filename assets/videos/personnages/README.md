# 🎥 Personnages filmés — Le Secret de la Déclaration

Vidéo en boucle, cadre portrait vertical, jouée **muette** (la voix vient de
la synthèse vocale).

| Fichier | Personnage |
|---|---|
| `louise.mp4` | Louise |
| `gutenberg.mp4` | Maître Gutenberg |
| `marquis.mp4` | Le Marquis de Montclair |
| `maximilien.mp4` | Maximilien |

**Variante « en train de parler » (optionnelle)** : ajoutez `louise-parle.mp4`,
etc. Le jeu bascule dessus tout seul pendant que le personnage parle, puis
revient à la boucle de repos.

Sans fichier, le jeu essaie une image dans
[`../../images/personnages/`](../../images/personnages/), puis retombe sur
le personnage dessiné animé.
